# Triage 标签

这些技能使用五个规范的 triage 角色。本文档将这些角色映射到本仓库 issue tracker 实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库使用的标签 | 含义 |
| -------------------------- | ---------------- | ---- |
| `needs-triage`             | `needs-triage`   | 等待维护者评估此 Issue |
| `needs-info`               | `needs-info`     | 等待报告者补充更多信息 |
| `ready-for-agent`          | `ready-for-agent`| 信息完整，可交给 AFK agent 处理 |
| `ready-for-human`          | `ready-for-human`| 需要人工实现 |
| `wontfix`                  | `wontfix`        | 不会处理 |

当技能提到某个角色时（例如“应用 AFK-ready triage 标签”），使用此表中对应的标签字符串。

请编辑表格右侧一列，使其匹配你实际使用的标签词汇。
