```text
Garbage-First 垃圾优先

大对象？
Card table 和 Remembered set
```

## 处理过程

1. **纠错**：将 `Regin` 规范为 `Region`。
2. **标题与标签**：生成类似 `# G1 垃圾收集器：Region 化、回收策略与跨区引用` 的具体标题，以及 `#视频笔记 #Java #JVM #G1GC` 等相关标签。
3. **结构重建**：按"背景与特点 → Region 布局 → Garbage-First 含义 → 大对象 → 跨代/跨 Region 引用"组织。
4. **问号式碎片展开**：将"大对象？"展开为 Humongous Object 小节；涉及具体阈值或版本参数时先核验再写入。
5. **概念深度解释**：解释 Card Table 与 Remembered Set 的职责、差异和协作流程，不只改写原句。
6. **冲突处理**：将过度简化或具有版本差异的说法放入"补充与校正"，不悄悄覆盖原笔记。
7. **总结**：用 3～5 条完整结论总结 G1 的内存布局、回收策略和引用跟踪机制。
